本目录给出《档案库管理系统》的业务流程框图（泳道式）及其文字说明，可直接放进论文/项目文档。

## 二、怎么看这张图

图是**泳道式流程图**：三条竖泳道 = 三类角色，每条泳道自上而下 = 该角色的操作顺序。

| 图形 | 含义 |
|---|---|
| 圆角矩形 | 一个业务步骤（框内首行为步骤名，下面小字为要点） |
| 菱形 | 判断分支（是/否、不同密级、不同期限），分支出口文字写在箭头旁 |
| 实线箭头 | 主干流程，自上而下推进 |
| 虚线箭头 | 泳道之间的协作或数据传递 |
| 顶部深色框 | 统一入口：浏览器 / 内网 B/S / 自助终端 |

三条泳道对应的角色分工：

- **读者 / 利用者**：查档、用档的人（教师、学生、业务部门、社会公众）。
- **档案管理员**：档案的收集、整理、著录、保管、借阅审批、鉴定销毁。
- **系统与管理层**：用户与权限、审计日志、备份恢复、定时任务与统计。

## 三、流程说明

### 3.1 读者 / 利用者泳道

1. **注册 / 登录**：账号密码登录，或校内统一身份认证（读者证号 + 密码）。
2. **身份与权限校验**：未通过则提示错误并累计失败次数，3 次锁定账号；通过则按读者 / 档案员 / 管理员分配角色权限。
3. **进入档案门户**：首页给出本馆概况、新入藏档案、通知公告、热门档案、办事指南。
4. **目录浏览**：按「全宗 — 目录 — 案卷 — 文件」四级目录逐层浏览馆藏。
5. **多条件检索**：题名 / 责任者 / 形成时间 / 主题词 / 档号 / 全文关键词组合检索；命中为空时提示扩大范围或改用模糊检索，回到检索步骤。
6. **检索结果列表**：分页返回命中条目，显示题名、时间、保管期限与状态。
7. **案卷详情与全文预览**：元数据 + 全文 / 影像预览 + 开放程度说明 + 借阅申请入口。
8. **权限判定（判断）**：
   - 开放档案 → 直接在线阅读；
   - 控制 / 涉密档案 → 需审批，并留下访问痕迹；
   - 未授权 → 退回浏览。
9. **阅览 / 下载**：在线阅览、打印、受控下载，系统自动记录访问日志。
10. **提交借阅申请**：填写用途与借期，选择原件借出或复制件，提交后进入档案员的审批队列（虚线跨泳道）。
11. **借出登记**：审批通过后办理出库，登记借阅人与归还期限，生成借阅凭证。
12. **到期提醒**：到期前 3 天提醒；逾期未还则暂停借阅权限并进入催还流程。
13. **归还 / 破损处理**：核验档案完整性与密级，放回库位并更新状态；若有破损则登记异常并补做复制件。
14. **退出系统**：会话销毁，超时自动登出。

### 3.2 档案管理员泳道

1. **登录后台管理系统**：使用档案员账号进入内网 B/S 管理端，功能按角色授权。
2. **归类分流（判断）**：新收档案进入著录流程；借阅申请进入审批流程。
3. **著录与标引**：登记档号、题名、责任者、形成时间、保管期限、密级、载体形态，按分类方案归类并标引主题词。
4. **OCR / 全文提取**：纸质扫描、电子文件解析，生成全文文本与检索索引（供读者全文检索）。
5. **著录校验与查重**：校验档号唯一性、字段规范、重复件；不合格退回补录。
6. **实体上架与数字化归档**：纸质原件库房排架并登记库位号（密集架—柜—格）；电子档案入库服务器双副本并做防篡改校验。
7. **库位索引**：建立「档号 ↔ 库位 / RFID / 条码」映射，支持扫码快速定位。
8. **档案调取**：按档号或扫码调取原件与复制件，登记出库，核对库位并更新状态；库位不符则报异常并回退核对。
9. **借阅审批（判断）**：一般档案由档案员直接审批；重要 / 控制档案报主管领导审批。审批结果回流到读者的「借出登记」。
10. **归还核验与续借**：核对份数与完整性，办理续借，异常情况登记并上报。
11. **到期鉴定（判断）**：已达保管期限的提请鉴定销毁；未到期的继续保存。
12. **鉴定与销毁**：鉴定小组复审，报批后监销并登记销毁清册；未通过则继续保管。销毁清册与鉴定记录归档到审计日志。
13. **退出系统**：登出并保留操作日志。

### 3.3 系统与管理层泳道

1. **系统自动运行**：定时任务——逾期提醒、库房盘点、日志归档、统计报表；到期提醒推送给读者。
2. **用户 / 角色 / 权限维护**：账号增删改、角色授权、权限矩阵配置、密级分级管控；接收读者登录时的身份信息。
3. **审计日志**：记录操作、访问与借阅行为，支持追溯到人、防篡改留存。
4. **数据备份与恢复**：全量 + 增量备份，异地 / 异质保存，定期恢复演练。

## 四、关键业务规则汇总

| 环节 | 规则 |
|---|---|
| 登录 | 连续失败 3 次锁定账号；超时会话自动登出 |
| 开放程度 | 开放档案直接阅览；控制 / 涉密档案须审批且访问留痕 |
| 著录 | 档号唯一、字段规范、查重通过后方可上架 |
| 库位 | 档号与库位 / RFID / 条码一一映射，调取需核对 |
| 借阅 | 一般档案档案员审批；重要 / 控制档案报主管领导 |
| 期限 | 到期前 3 天提醒；逾期停借并催还 |
| 销毁 | 到期 → 鉴定 → 报批 → 监销 → 登记清册，全程留档 |
| 安全 | 全量 + 增量备份、异地异质保存、恢复演练 |

## 五、数据流（跨泳道）

| 起点 | 终点 | 传递内容 |
|---|---|---|
| 读者：提交借阅申请 | 档案员：借阅审批 | 借阅单（用途、借期、原件 / 复制件） |
| 档案员：借阅审批 | 读者：借出登记 | 审批结果与授权范围 |
| 档案管理员：鉴定与销毁 | 系统：审计日志 | 销毁清册、鉴定记录 |
| 读者：身份与权限校验 | 系统：权限维护 | 身份信息 → 角色与密级权限 |
| 系统：自动运行 | 读者：到期提醒 | 到期 / 逾期提醒通知 |

## 六、如何改图与重新生成

改文字、改颜色、改流程，只需编辑 `draw-archive-flow.mjs` 里的 `READER` / `CLERK` / `SYS` 三个数组（每个节点写 `t` 步骤名、`d` 说明），然后重跑：

```powershell
pwsh -File render-png.ps1
```

脚本会依次完成：提取文案 → 浏览器实测中文字宽做精确换行 → 生成 `archive-flow.svg` → 用 CDP 精确导出 `archive-flow.png` 与 `archive-flow@2x.png`，并自动校验标题区域是否正常渲染。

环境要求：Node.js 18+、Microsoft Edge（或 Chrome）。脚本会优先找 Edge，未安装时 SVG 仍可单独使用。

> 实现说明：PNG 不走 `msedge --screenshot`（无头模式对截图尺寸有约 750 px 的硬上限），也不走 `--print-to-pdf`
> （Chrome 打印会把粗体中文回退成 Type 3 字体子集，多数 PDF 渲染器画不出来，标题会整块丢失）。
> 这里用 CDP 的 `Emulation.setDeviceMetricsOverride` + `Page.captureScreenshot`，渲染结果与屏幕所见一致。
