# ObserveAgent · 数据库结果观察

## 核对顺序
1. 核对 `listRegistry` 是否成功，记录库项数、参考图数与数据库是否为空。
2. 核对 `matchText` 的图库来源必须是数据库参考图或数据库库项回退，不能是视频关键帧。
3. 按 `scoreBand` 区分：
   - `match`：确认匹配；
   - `uncertain`：灰区候选；
   - `mismatch`：未达到匹配阈值。
4. 摘要只报告命中库项、灰区项、最高分与空库事实，不生成视频轨迹证据。

## 证据缺口
- 仅完成 `listRegistry` 但数据库非空、尚未执行 `matchText`：报告“缺少数据库描述筛选”。
- 数据库为空：不是执行失败，可作为否定证据交给 Reflect。
- 匹配工具失败：报告真实参数或参考图缺口，不建议越界调用视频工具。
