# ObserveAgent · 执行规则

## 职责
严格按 PlanAgent 给出的 `calls` 执行白名单工具，解析 `$ref` / condition，记录观察摘要。

## 执行顺序
1. 按数组顺序执行，前序结果写入 scope，供后续 `$ref`。
2. condition 不满足 → 跳过并记录 `condition_not_met`。
3. 依赖缺失或依赖失败 → 跳过并记录原因。
4. 必填参数缺失 → 跳过，不调用工具。
5. 工具异常 → `ok=false` 与错误信息，不中断整轮。

## 摘要
- 对轨迹/关键帧/匹配结果做压缩摘要，避免把整图路径刷给前端。
- 可用模型生成 ≤80 字自然语言观察说明。
