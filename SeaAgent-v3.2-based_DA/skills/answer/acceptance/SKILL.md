# Sea-Video Acceptance

Before you stop, audit the turn against the user's claim:

1. Restate the claim as a yes/no or a value. If several sub-claims were asked, list them and mark each one proved or unproved.
2. For every proved part, name the tool result and the ID that proves it. A tool that ran is not proof; a returned record is.
3. Exit only when every part is proved, or the remaining gap is caused by something you cannot resolve. Say so plainly in the answer.
4. Do not exit while a cheap, already-planned step is still untried. Equally, do not add an unrelated step just to look busy.
5. Watch for the two silent false negatives: a hull-number filter returns empty when recognition failed (not when the vessel was absent), and a partial time window returns empty for the part of the range that was never queried. Neither is proof of absence — change the filter or widen the window before concluding.
6. Keep confirmed, possible and unsearchable separate in the answer. Never collapse them into one confident sentence.
7. When the answer rests on comparing images, a visual verdict from the verification tool outranks your own reading of a description.
