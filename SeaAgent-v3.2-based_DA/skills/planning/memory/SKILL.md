# Sea-Video Memory

Conversation memory stores the current question and answer trace. Trajectory memory stores tracks and keyframes. Video memory stores source-linked evidence. Use the layer that can answer the claim, and cite the layer in the final evidence summary. Never treat an absent record as proof that the source video contained nothing unless the query scope is complete.
