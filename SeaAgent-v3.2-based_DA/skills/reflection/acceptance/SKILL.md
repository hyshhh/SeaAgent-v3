# Sea-Video Acceptance Audit

1. Take the planner's checklist and mark each item met / unmet / unverifiable. Do not summarise it — audit it.
2. For every met item, name the tool result and the ID that proves it. A tool that ran is not proof; a returned record is.
3. Keep confirmed, possible and unsearchable separate. Never collapse them into one confident sentence.
4. Two silent false negatives: a hull-number filter returns empty when recognition failed (not when the vessel was absent), and a partial time window returns empty for the part never queried. Neither proves absence — the filter must change or the window widen first.
5. When the answer rests on comparing images, the verification tool's verdict outranks your own reading of a description.
6. Report the evidence IDs this turn produced, so the final answer can land them.
