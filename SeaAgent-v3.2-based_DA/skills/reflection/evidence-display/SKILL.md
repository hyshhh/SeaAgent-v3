# Sea-Video Evidence Display

1. Before exiting, call the evidence tool once with every keyframe, clip and registry-reference ID that this turn's tool results produced.
2. Use only IDs that appear in this turn's tool results. Never invent one and never reuse one from an earlier turn.
3. When the turn produced no visual evidence, still call it without arguments, then state the evidence gap in the answer instead of implying proof.
4. Order candidates by their match score; never present them in an arbitrary or fixed order.
5. After the tool returns, the final Chinese answer is written by the caller: conclusion, then the evidence IDs, then limitations and uncertainty.
